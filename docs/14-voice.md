# 人声：让一句文字唱出来

需求很直白：**输入一句话，能说，也能唱。**

能想到的第一条路是接一个 TTS / 歌声合成模型。这条路在这个项目里走不通 —— 不是模型不好，
是 Kinelayer 的底座不允许：纯前端、可离线、同一个工程在任何机器上出同样的片子。
一个几百 MB 的 ONNX 模型塞进浏览器，前面三条全部作废。

所以先去看开源世界把这件事拆成了几段，再决定我们只做哪几段。

---

## 一、调研：五个项目，三条路线

★ 与时间是 2026-10 调研时的快照，会漂；这里记的是**技术路线**。

| 项目 | 定位 | 关键做法 | 它真正在解的问题 |
| --- | --- | --- | --- |
| `nnsvs/nnsvs` | 歌声合成的**训练-推理框架**（MIT） | 拆成四段：**时长模型 → 音高(F0)模型 → 声学特征 → 声码器**；每段一个轻量网络，可换实现 | 把「乐谱 + 歌词」变成「时序参数」，且每段都能单独替换与调试 |
| `openvpi/DiffSinger` / `stakira/OpenUtau` | 神经歌声合成 + 编辑器 | 端到端扩散模型出 mel 谱；编辑器里用 `breathiness` / `tension` / `pexp` / `velocity` 这些**表情参数**做微调 | 唱得像人：连滑、换气、颤音、力度都能被一个滑块控制 |
| `klattsch`（JS） | 浏览器里的**并联共振峰**合成器 | 零依赖；输入是「ARPABET 音素串 + 音符分组」；清浊交替 + 共振峰滑动 | 不装模型也能在浏览器里发出听得懂的语音 |
| `espeak-ng/espeak-ng` | 规则式 TTS，107 种语言 | 全量仅 ~1.4 MB：**一种语言 = 一张音素表 + 一套转换规则**；共振峰合成（Klatt） | 覆盖度优先：小体积、可离线、语言可扩展 |
| `klatt-syn` / Klatt 1980 论文 | 经典**共振峰合成器** | 声门源 + 若干串联/并联共振峰 + 噪声支路；每个音素就是一组 F1/F2/F3 | 参数化语音：一切都是可解释的数字，没有黑盒 |

### 三条路线的取舍线

1. **神经端到端**（DiffSinger / OpenUtau）：质量最好，代价是模型几百 MB、要 GPU、首帧延迟按秒算，
   而且**不确定** —— 同一段文本两次推理会有细微差异，离线渲染的可复现性直接丢掉。
2. **神经分段**（NNSVS）：每段都小，理论上能塞进浏览器（几百 KB 的时长模型 + 几十 MB 的声码器）。
   但声码器那一段绕不过去，且四段串起来调试成本高。
3. **规则 + 共振峰**（eSpeak NG / klattsch / Klatt）：**零模型、确定性、参数即音色**。
   代价是「像机器在唱」——但对一个可编程海报工具来说，这条代价可以接受，甚至是个特点。

### 我们选了什么

**走第 3 条，但按第 2 条的骨架组织代码。**

- 骨架抄 NNSVS：分成「文本 → 音节」「音节 → 音素」「音素 → 计划（时长 + 音高）」「计划 → 声音」四段，
  前三段是 `src/core/voice.ts` 里的纯函数（不碰 WebAudio、不碰 DOM），第四段才是 `src/render/voiceSynth.ts`。
- 音素表抄 eSpeak NG 的思路：**一种语言 = 一张表 + 规则**。中文缩水成「1015 个常用字 → 拼音」+「声母表 + 韵母归并」。
- 发声顺序抄 klattsch：先清辅音（噪声开门），再元音（共振峰就位），音节之间用滑音连起来。
- 表情参数抄 DiffSinger 的三个名字：`breath`（气声）、`vibrato`（颤音）、`rate`（语速）。

## 二、长什么样

```
一句话  ──syllablesOf──▶  音节[]  ──pinyinToPhonemes──▶  音素[]
                                                            │
                                                    buildVoicePlan
                                                            ▼
                            计划 { notes[{atMs,ms,f0,f0End,phonemes[]}], totalMs }
                                                            │
                                                   renderVoiceBuffer
                                                            ▼
                                              AudioBuffer（44.1k，单声道）
```

### 1. 切音节：三种写法混着来

`syllablesOf(text)` 一条流水线吃掉三类输入，可以混写：

| 输入 | 处理 |
| --- | --- |
| 汉字 | 查 `HANZI` 表（1015 字）得拼音；表里没有 → 记 `unknown`，用 `la` 顶上，界面上提示「把这几个字写成拼音」 |
| 数字 | 按读法逐位转（`2026` → `er ling er liu`） |
| 拉丁字母 / 拼音 | 直接当拼音解析，`ni hao` 和 `你好` 等价 |
| 标点 | 不占音节，只产生停顿（逗号 180ms、句号 320ms、换行 300ms…） |

「表里没有就写成拼音」不是偷懒，是这套设计的逃生门：**任何生僻字都能靠拼音唱对**，
不需要为了几个字去扩表。

### 2. 拆音素：声母按长度倒序匹配

`pinyinToPhonemes('zhuang')` 必须先认出 `zh` 而不是 `z` —— 所以 `INITIALS` 按长度倒序排（`zh/ch/sh` 在 `z/c/s` 之前）。
韵母做了一层归并（`FINAL_ALIAS`）：`ian/iang/uan/…` 这些复韵母落到少数几个共振峰目标上。
39 个音素覆盖了普通话的全部声母 + 主要韵母，比 eSpeak NG 的完整表粗，但足够听清。

每个音素带三样东西：`f1/f2/f3`（元音才给）、`noise`（辅音的噪声频带）、`voiced`（清浊）。

### 3. 排计划：时长和音高各一套规则

**说**：每个音节 `BASE_MS / rate`，加停顿。
**唱**：每个音节占 `beatsPerSyllable` 拍，`60000 / bpm * beats` 毫秒；音素按比例分配，余量补给最后一个元音
（元音拉长比辅音拉长自然）。

音高：`root`（女 220 / 男 110 / 童 300 / 机器人 130）为基准，加 `pitch`（半音）与旋律。
没给旋律时用 `AUTO_MELODY = [0,2,4,7,4,2,0,-3,…]` —— 五声音阶 + 回旋，听得出「有曲」，且完全确定。

**时长由 core 算**，不由渲染层量：`voice.create` 在毫秒级就能拿到准确长度并写进 `outPoint`。
反过来做（先建层、渲染时量、再回写）会让时间轴出现一次「先长后短」的跳变。

### 4. 出声：声门 + 三个共振峰 + 噪声

`renderVoiceBuffer` 在 `OfflineAudioContext` 里搭一张图，每个音符一套：

- **声门源**：`sawtooth` 振荡器。锯齿波的谐波丰富，经过带通就是人声的底子。
- **三个并联带通**：Q 7 / 10 / 14，增益 1 / 0.55 / 0.3，中心频率按音素搬 F1/F2/F3。
  并联而非串联：串联会让一个共振峰吃掉另一个，并联更像真实声道的叠加。
- **噪声支路**：清辅音（b/p/f/s…）靠它；同时给浊音段一路很小的气声底（`breath * 0.05`），
  不然听起来像纯蜂鸣器。
- **辅音抢拍**：音节以清辅音开头时，让辅音提前 `min(60ms, 辅音时长*0.7)` 进来。
  这是歌声合成的常规做法（OpenUtau 的 consonant velocity），不提前每个字都「慢半拍」。
- **滑音**：`lastF0 → note.f0` 用 60ms 以内的线性斜坡，再从 `f0` 滑到 `f0End`。没有这一步，连句会「跳音」。
- **颤音**：LFO 5.4Hz（唱）/ 3.2Hz（说），深度 `f0 * 0.022 * vibrato`。连到 `frequency` 上是「加」上去的，所以按比例给。
- **音色**：`FORMANT_SCALE`（女 1 / 男 0.88 / 童 1.18 / 机器人 0.95）整体缩放共振峰 —— 声道越短，共振峰越高。

**噪声必须是确定性的。** 代码用 LCG（`seededNoise`），不用 `Math.random`：
同一个工程在不同时间导出必须得到同一段音频。

## 三、抄了谁，拒了谁

| 来源 | 借的 | 不借的 | 理由 |
| --- | --- | --- | --- |
| NNSVS | 四段式分层、时长与音高分离 | 神经网络本身 | 纯前端装不下、不可复现 |
| DiffSinger / OpenUtau | `breath` / `vibrato` / `rate` 三个表情参数的命名与语义 | 扩散模型、几百 MB 模型 | 模型体积与首帧延迟 |
| klattsch | 并联共振峰、清浊交替的发声顺序 | ARPABET（中文用不上） | 中文有自己的音素集 |
| eSpeak NG | 「语言 = 表 + 规则」的组织方式 | 完整 107 语言表 | 我们只要中文，且不要 IPA |
| Klatt 1980 | F1/F2/F3 + 噪声支路的结构 | 串联式与高阶参数 | 并联更简单，听感够用 |

## 四、三条命令

| 命令 | 管什么 | 谁决定时长 |
| --- | --- | --- |
| `voice.create` | 从一句话新建一层 | `buildVoicePlan`（唱完为止） |
| `voice.sync` | 词改了之后重算长度，起点不动 | 同上 |
| `voice.set` | 只改参数（音色/气声/颤音/旋律），`refit:false` 时不动长度 | 默认重排，`refit:false` 保留 |

```json
{
  "type": "voice.create",
  "payload": {
    "text": "我在加我的图层数",
    "mode": "sing",
    "preset": "female",
    "beatsPerSyllable": 1,
    "at": 800
  }
}
```

返回 `{ id, inPoint, outPoint, ms, syllables, phonemes, unknown, text }` —— 一次调用就能知道「唱了多久、几个字、几个字不认识」。

人声层仍是 `AudioLayer`，靠 `voice` 字段区分音源。三条音源**互斥且有序**：`voice` > `assetId` > `tone`。
混音、波形、摘要都走同一条分支，避免出现「人声裁了但导入音频没裁」这类不对称 bug。

## 五、界面

- **左栏「音频 → 人声」**：上面一个输入框，中间「说话 / 演唱」分段 + 四个音色，右下角一个蓝色主按钮
  「生成到时间轴 / 应用到这一层」。音高、语速、颤音、气声折叠在「音色细节」里，不展开也能直接生成。
- **选中人声层时，这块面板就是在编辑那一层**（改了立刻生效、可撤销），没选中时才是新建草稿。
  两种状态走同一条命令路径，不出现「预览一套、生成另一套」。
- **检查器**里人声层只显示词、模式、音色和字数，另给一个「去人声面板编辑」直接跳过去。

## 六、已知限制

按「用户会先撞上哪个」排序：

1. **一字一音**。演唱是「每个音节一个音符」，没有一字多音的转腔、滑腔。想要更花，只能给 `melody` 传更细的音符序列。
2. **没有声调**。拼音表不带声调，音高完全由旋律决定。说话模式的抑扬靠一个整体包络近似，念多音字会不对。
3. **一个多音字只有一个读音**。表里存的是最常用的那个（`了` = `le`，`行` = `xing`）。要别的读音，把那句里的字直接写成拼音。
4. **1015 字之外退化成「啦」**。面板会提示有几个字没读音；把它们写成拼音就能唱对。
5. **没有连读变调、儿化、轻声**。中文这些细节要靠词典 + 规则表，目前都没做。
6. **不是逐位可复现**。`OfflineAudioContext` 同一张图跑两遍，末位会差 1~2 个 float32 ULP（实测 `maxDiff ≈ 3e-8`），
   16bit WAV 里可能有极个别样本差 1 个最低位。听不出来，但**「两次导出的文件 sha256 相同」这个承诺给不了**。
   `scripts/voice-check.mjs` 因此按「逐样本偏差 < 1e-6」判复现性，不按校验和。
7. **机器味**。共振峰合成的天花板就在这儿。想更像人，就得请回神经网络，而那与本项目的底座冲突。

## 七、自检

`scripts/voice-check.mjs`（dev server 跑在 5273）共 47 条，分七组：

| 组 | 断言什么 |
| --- | --- |
| 切分 | 汉字/数字/拼音混写的音节、标点停顿、生僻字标 `unknown` |
| 计划 | 说话比演唱短、`rate` 加倍更短、每字两拍更长、给旋律就按旋律走、音符不重叠 |
| 渲染 | `peak/rms` 非零、长度等于计划、换音色换词都换样本、`ms` 上限截断 |
| 复现性 | 同 spec 两次渲染逐样本偏差 < 1e-6、长度一致 |
| 命令 | 起点落播放头、层长 = 计划长、改词自动变长、`refit:false` 不动长度、越界入参被拦 |
| 接线 | 排程报 `voice:xxx`、离线混音有声、波形只在人声那几桶里有能量、`query.project` 摘要带人声 |
| 界面 | 「音频」页签 → 人声面板 → 点生成多一层且词正确；选中后检查器有入口 |
